# Security policy

Repo Sentinel is a heuristic static scanner. It is not a substitute for security review, language-native analyzers, dependency auditing, or runtime controls.

To report a security issue in this project, contact the maintainers privately before opening a public issue. Include the affected rule or component, a concise impact description, and a safe reproduction where possible. Do not include real credentials or personal data.

Rules are designed to favor understandable findings and actionable remediation. Report false positives or missed patterns with a minimal non-sensitive example so the rule can be reviewed and added to the regression fixtures.
